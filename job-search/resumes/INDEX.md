# Tailored Resumes — Fortune 300 Analyst Openings

Generated 17 August 2026. One resume per posting from the **Prior business days** tab of `Fortune300_Analyst_Openings_48h.xlsx` (postings 2–7 days old as of the 17 Aug pull).

**35 resumes.** Each is tailored to that posting's actual job description, fetched live from the employer's applicant-tracking system — not written from the job title.

## How these were tailored

Every job description was scored against nine role families (requirements/SDLC, data & BI, governance, technical/systems, data engineering, statistical, supply chain, financial, healthcare). The dominant families then drive the summary, the competency band, which skill groups appear first, and which experience bullets are selected and in what order.

**Nothing is invented.** Every bullet traces to the baseline resume or to a capability Ahmad confirmed directly (JIRA, Confluence, governance catalog tooling, MDM/metadata/lineage, test cases & QA, user stories, UAT, mentoring, cloud, CI/CD, SAS, NLP, Palantir, Visio, Smartsheet, SAFe, healthcare payer/claims). Those confirmed items appear **only where the job description asks for them**.

## Format

ATS-safe by construction: single column, no tables, no text boxes, no header/footer content, standard section headings, Calibri throughout. Verified programmatically across all 35 files. Roughly one to one-and-a-half pages each (~650 words).

- **Healthcare payer/claims still needs a home.** It appears on the healthcare-family resumes because you confirmed the experience, but neither employer on the resume is payer-side. If it came from a role or project not listed, add it so an interviewer can trace it.

- **Postings expire.** These were live on 17 Aug 2026. Check the link before applying.

- **Layout not visually proofed.** The container that generated these has no Word/LibreOffice renderer, so structure and formatting were verified programmatically but not eyeballed. Open one before sending the batch.
